概览

启动应用后先在这里检查环境；绿灯齐全就能进"运行测试"。

项目路径

本应用所有测试都在这个目录里跑；没配过或想换目录都在这里改。优先级：环境变量 > 本处保存 > 已解压默认模板 > 自动扫描。

还没有可用的项目路径

上面"项目路径"卡里选一个含 package.json + playwright.config 的目录；没有现成工程的话点「解压默认模板并使用」。

找不到 Node.js

本应用需要 Node.js 22+ 才能跑 Playwright。下面三种方式任选一种，装完回到此面板点"重新检测"。

  1. 最快（推荐测试人员）：点上面"Node 官网下载"，下载对应系统的安装包，一路下一步
  2. 开发机 · Mac/Linux：装 nvm → nvm install 22 && nvm use 22，应用会自动识别 ~/.nvm/versions/node/ 下的版本
  3. 开发机 · Windows：装 nvm-windows → nvm install 22.10.0 && nvm use 22.10.0，应用会自动识别 %APPDATA%\nvm\ 下的版本
检测到已装的 nvm 版本（未激活）：

    应用已把这些目录加进子进程的 PATH，理论上可以直接用。点"重新检测"确认。

    首次使用：一键准备测试环境

    依次跑两步。全程不需要开终端，首次 3–6 分钟，之后秒进。

    1. pnpm install — 安装 JS 依赖（含 Playwright）
    2. pnpm install-browsers — 下载 Chromium（首次约 200MB）

    装坏了？点「修复安装」会先清掉 node_modules 再重来。

    第二步：填测试账号

    直接填下面的表单；保存后会写进项目根的 .env.local（已存在则保留注释与其他字段，只更新 key）。

    准备好之后

    • 切到「运行测试」点「冒烟 @smoke」快速跑一轮看是否打通
    • 要录制新流程，去「录制与导入」面板，填一个用例名点启动
    • 所有报告会落在「报告」面板里，双击打开即可

    运行测试

    直接调用工程中既有的 pnpm 脚本，不会额外安装 Playwright 依赖。
